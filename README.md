# Montajes Sublimación

Aplicación local para organizar pedidos, montajes, piezas a imprimir y hojas de corte y costura. Versión 1.28.4 basada en la v1.28.3 original de Claude.

Abrir `Montajes-Sublimacion.html` en el navegador. Los pedidos e imágenes se almacenan en el navegador; no viajan con el HTML. Exportar respaldos desde Historial y conservarlos fuera del repositorio antes de cambiar de navegador, origen o versión. No subir datos reales.

Documentación de trabajo: `AGENTS.md`, `docs/ESTADO_ACTUAL.md`, `docs/BITACORA.md`.
